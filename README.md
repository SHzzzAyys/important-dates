# 重要日子

一个单文件 HTML 重要日期提醒工具，支持阳历和农历，开箱即用，无需安装。

## 功能

- **阳历 / 农历**：支持按农历（如正月初一）设置每年重复事件，自动换算当年对应公历日期
- **生日年龄**：生日类型可填写出生年份，表格实时显示「今年 X 岁」
- **浏览器通知**：开启通知权限后，每次打开页面自动检查近期日期并弹出提醒，支持提前 3/7/14/30 天预警
- **节日快速添加**：内置 12 个中国传统节日（春节、端午、中秋等），一键加入列表
- **数据导出 / 导入**：将所有数据导出为 JSON 备份，换设备后直接导入恢复

## 使用

直接用浏览器打开 `index.html`，无需服务器，无需 npm。

**设为浏览器启动页**可实现每日自动提醒。

## 数据存储

所有数据存在浏览器 `localStorage`，不联网，不上传。

## 技术栈

- [Tailwind CSS CDN](https://tailwindcss.com)
- [lunar-javascript](https://github.com/6tail/lunar-javascript) — 农历 ↔ 公历转换
- [JetBrains Mono](https://www.jetbrains.com/lp/mono/) — 数字等宽字体
